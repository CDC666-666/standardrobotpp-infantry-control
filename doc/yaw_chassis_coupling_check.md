## 1.45/1.25 下仍过中：枪管不摆，转查底盘回正制动

用户进一步确认：手动 yaw 前馈为 1.45 或 1.25 都会在退出旋转后，底盘越过云台中值一点，再逆时针回来；过中期间枪管相对地面不明显摆动。本轮开始时本机前馈已被用户改为 1.25，中值为 -0.540360451；均保留，未回退。按此前 N 档及 S 档无目标范围检查。

这把主要排查方向从“云台移动导致底盘追随新目标”收窄到底盘跟随的减速/收敛过程。它不证明云台电机对底盘的反作用力矩为零，也不单独证明减小前馈是过冲的唯一原因。此前 1.45 把匀速偏角降至约 0.284° 的结果仅验证该稳态工况，不能当作退出回正动态通过。

当前源码的 N/S 无目标回正与 FOLLOW 已使用同一个关节角。回正速度上限仍 ±6 rad/s；外环位置 Kp=13.5、离散 Kd=5.05，另减去 0.95*P_wz；底盘速度环 Kp=6.4051013。已有角差相关减速与角速度阻尼，不是没有制动。到中心但余速仍超过 0.03 rad/s 时，不启动 100 ms 稳定计时，继续 RETURN。

另一个调参陷阱：实际 PID 的 D 项是逐拍误差差分，没有除以 dt。底盘任务名义延时 2 ms 时，Kd=5.05 对平滑变化误差的连续速率项量级约为 0.0101（实际周期还包含任务计算/调度）；不能把 5.05 直接当成很强的角速度阻尼。直接角速度阻尼 0.95 与其不是同一量纲约定。

后续处理方向是仅对 N/S 无目标的 RETURN 做临近中点减速或加强角速度制动，保留远处回正上限、正常跟随、自瞄 S 有目标固定回正→BODY；先固定 yaw 前馈再独立调底盘，避免用重新引入枪管世界角静差来掩盖底盘过冲。本轮只诊断和记录，没有新增生产控制参数或修改控制逻辑，未重新 Keil 构建、烧录、提交或推送。

## 检查结论及证据边界

**代码及主机执行确认：退出小陀螺存在两个不同的底盘朝向目标，切换前还要求稳定 100 ms。这能形成两段回正。不能仅据此认定用户观察到的右偏已唯一定位。**

若松手时云台实际朝向为 A，后来恢复到 B，固定回正先对准 A，正常跟随再对准 B。两目标差等于 `wrap(A-B)`。以人为输入的 ±15° 偏差执行实际状态机、实际底盘 C 文件和实际 PID，可复现旧目标到位后输出零、保持 100 ms、随后切换参考。该复核没有底盘动力学、摩擦、传感器延迟或轮胎滑移模型，不能预测实车角度与停顿时长。

还有一个方向约束：若松手保存的 A 在 B 左边，且 `yaw_world-yaw_joint` 与实车朝向一致，那么旧目标也应在 B 左边。用户确认的第一处停车位置在右边，不能直接等同于“停在保存的左偏目标”；仍需核验动态过冲、反馈方向及松手沿实际采样的世界角。这里没有改 yaw 中值或方向参数。

## 实际链路

1. `GimbalReference()` 在 N 档保持手动世界角 `reference.yaw`；按住/松开小陀螺不会单独改云台模式或重置这个角度。摇杆仍可修改它。
2. 手动 yaw：`速度目标 = 10*wrap(reference.yaw-feedback_pos.yaw) - 0.25*feedback_vel.yaw + 2*chassis.P_wz`，再乘电机方向并限幅 ±20 rad/s；与 DM 关节速度的差经过 Kp=1.25 的速度环，得到限幅 ±7 N·m 的力矩。前馈在回正和普通跟随期间同样生效，并非只有小陀螺模式才生效。N 档不走自瞄 LQR/ESO，也不使用自瞄的 2.5 力矩前馈。
3. 云台发布实际 `yaw_world` 和相对机械中值的 `yaw_joint`；底盘由 `wrap(yaw_world-yaw_joint)` 推算世界朝向。`GetGimbalDeltaYawMid()` 与 `CmdGimbalJointState(AX_YAW)` 采用相同的方向、机械中值和折返公式，未发现这两个接口使用不同中值。
4. `Vt13UpdateSpin()` 松手沿保存的是实际反馈 `yaw_world`，不是手动目标 `reference.yaw`。`CHASSIS_SPIN_RETURN` 固定追这个保存值，目标角速度限幅 ±6 rad/s。
5. 回正误差 <0.03 rad（约 1.72°）、轮速估计角速度 <0.05 rad/s 连续 100 ms 后，N 档转为 `CHASSIS_FOLLOW`。参考计算自身的停止区更小，为 0.015 rad（约 0.86°）和 0.03 rad/s。这两个阈值不是同一个“已回中”标准。
6. 转入跟随后改用当前 `yaw_joint`，等效目标变成当前云台实际方向，限幅恢复 ±15 rad/s；模式切换清跟随 PID，但没有平滑两个角度目标。跟随 PID 的 Ki=0，底盘角速度环和手动 yaw 两级 PID 的 Ki 也均为 0，本机这条路径不支持积分积累的解释。
7. 底盘跟随结果减去 `0.95*P_wz`，得到目标角速度；角速度环 Kp=6.4051013 生成底盘期望力矩，再分配轮端力和电流。`P_wz` 是轮速解算值，不是独立底盘 IMU 测量。

## 15° 偏转及后续定位

当前没有“云台固定偏转 15°”的位置补偿；有的是随底盘速度连续变化的速度前馈。它可能因补偿系数、方向或速度口径不匹配而产生世界角静差，因此不能仅因加入了补偿就把可见偏角判为正常。手动参考不变、速度补偿随底盘减速消退时，云台恢复原方向符合现有结构，但本轮没有实测曲线来量化该过程。

优先在同一时间轴核对：`chassis.mode`、`chassis_spin_control.return_heading/settling/settle_start_ms`、`chassis_gimbal.yaw_world/yaw_joint`、`gimbal_direct.reference.yaw`、`chassis.reference.wz/P_wz`。在第一处停车点比较保存目标、推算底盘朝向和云台实际朝向：

- 若仍处于 RETURN，保存目标误差接近零，100 ms 后恰好转 FOLLOW，说明两目标切换参与了实车现象。
- 若异常发生时一直处于同一模式、同一目标，则重点检查制动过冲、摩擦和反馈符号；若计算朝向与肉眼方向相反，先查方向约定。

若期望“云台恢复原世界目标后，底盘一次回到该方向”，优先统一回正与跟随的目标及完成判据。例如无 yaw 摇杆操作时，可保存手动世界角参考而非受偏转影响的实际角；也可在受限速的回正阶段持续跟随当前云台方向。两者对回正过程中操作摇杆的行为不同，需要明确后再修改；本轮只检查，没有改变原固定松手朝向设计。单纯调小回正速度或调整中值不会消除两个目标来源的差异。
