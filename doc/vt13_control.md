# VT13 整车操控与接口

适用：`52da3e5` 之后的 N 档键鼠实现（2026-11-24 提交整理）。保留此前方向映射、回正限速与近中点制动；本次待提交快照通过主机测试，较早的 ARMCC 构建适用范围见末尾。VT03 链路在线后仍须等待云台实际回中，初始化完成前不放行底盘或发射。板上完整固件身份及键鼠实物效果未独立核验。

## 配置与回退

`application/robot_param.h` 默认选择：

```c
#define UART2_ROLE UART2_ROLE_VT13
/* 在 VT13 串口用途下，ROBOT_REMOTE_SOURCE 默认派生为 ROBOT_REMOTE_VT13。 */
```

`__RC_TYPE` 继续选择旧 USART3 接收器的类型，不要改为 `VT13`。车辆控制源单独由 `ROBOT_REMOTE_SOURCE` 选择；VT13 不写 `rc_ctrl`、不伪造 DT7 双拨杆、不刷新 DBUS 心跳。

需要保留 VT13 接收但恢复 DT7 车辆控制时，定义 `ROBOT_REMOTE_SOURCE=ROBOT_REMOTE_LEGACY` 后重新编译。切到 UART2 的 VOFA 或 LEGACY 用途时，默认恢复旧车辆输入。显式选择 VT13 控车但未启用 VT13 接收会产生编译错误。以上都是编译期选择，不会在 VT13 失联时自动切换遥控源。

## 操控表

| 输入/条件 | 行为 |
| --- | --- |
| 遥控无效、100 ms 无有效帧或 C 档 | 云台、四轮、摩擦轮、拨弹最终发送零力矩/零电流；清除开轮和回正状态 |
| C→N、C→S、失联恢复 | 云台先初始化；初始化完成前底盘和发射零输出 |
| N 档 | WASD 有输入时优先平移，鼠标移动时优先控制云台；键鼠空闲回到原摇杆，默认底盘跟随云台 |
| N 档鼠标右键 | 按住请求自瞄，松开回手动；有有效目标时复用原自瞄底盘坐标移动和自动开轮逻辑 |
| N 档鼠标左键 | 未进入有效自瞄时等效拨轮手动连发，仍需 Fn 开轮与到速；包括右键按住但无目标时 |
| N 档 Shift | 等效右上扳机按住小陀螺；Shift 与实体扳机都松开后进入原回正流程 |
| S 档无有效视觉目标 | 保留原摇杆手动与底盘跟随，不接入 WASD/鼠标瞄准/Shift |
| S 档有效视觉目标 | 云台自瞄；底盘不跟随，左摇杆按底盘前后左右平移 |
| 左 Fn，每次按下 | 切换手动摩擦轮开关；长按不重复切换；N 右键/S 档有效自瞄期间自动开轮 |
| 拨轮打到 −1 附近 | 未进入有效自瞄时请求手动连发；有效自瞄时不能覆盖视觉停火或左键松开 |
| N 右键/S 档视觉 `mode=1` | 跟踪并自动开轮，停止拨弹；左键和拨轮均不能绕过视觉停火 |
| N 右键/S 档视觉 `mode=2` | 只有鼠标左键同时按住才允许自动连发，松开立即取消拨弹 |
| 右上扳机键按住 | 小陀螺，平移沿用云台坐标规则；优先于有效自瞄时的底盘不跟随 |
| 未进入有效自瞄，扳机与 N 档 Shift 全部松开 | 持续对准当前云台方向，回正期间限速，到位后恢复正常跟随速度 |
| N 右键/S 档有效自瞄，扳机与 N 档 Shift 全部松开 | 保存松手当时云台朝向，固定回正后进入 BODY，不进入底盘跟随 |
| 回正结束 | N 右键/S 档实际自瞄则底盘坐标平移；否则跟随云台 |

回正仅恢复朝向，不恢复地面位置。回正期间允许按底盘坐标平移。未进入有效自瞄时，云台转动会同步更新回正目标；N 右键/S 档有效自瞄时保留松手固定朝向回正，完成后进入 BODY，不跟随当前云台。再次按住右上扳机或 N 档 Shift 取消回正并重新旋转。小陀螺对应原始 `trigger`，右上功能键 `function_right` 不触发旋转。

暂停键、右上功能键、未列出的键盘按键仍只保留原始解析，不新增操控映射。

## 键鼠优先与交接

- 键盘来自现有 VT03→UART 的有效帧；W/S 控制前后，A/D 控制左右。对向同时按下为零，仍覆盖摇杆；斜向输入归一化，避免数字方向键叠加超速。
- WASD 沿用 `CHASSIS_KEY_MAX_SPEED=6 m/s`、`CHASSIS_KEY_ACCEL=6 m/s²` 和 `CHASSIS_KEY_DECEL=6 m/s²`。松键后按当前摇杆目标平滑交接，交接完成恢复原摇杆响应；C 档、失联或初始化未完成立即清零，不等待平滑减速。
- 鼠标有位移的当前接收帧覆盖两轴摇杆；位移按 `mouse_x/y / MOUSE_SENSITIVITY` 每个新帧只消费一次，沿用 `40000` 灵敏度和俯仰限位。下一帧鼠标空闲时恢复摇杆增量，不把 14 ms 缓存位移按 1 ms 循环重复累加。
- 初始化、自瞄及 N/S 切换期间同步或丢弃旧鼠标位移；退出自瞄的第一拍捕获当前反馈角，不跳回旧手动参考。真实鼠标方向和灵敏度仍待台架确认。
- S 档仍使用原摇杆、扳机及自瞄入口；所有有效自瞄发弹统一增加左键按住条件。左键手动连发只在 N 档新增，S 档无目标仍使用原实体拨轮。

## 门控与阈值

- 任何拨弹都要求：初始化完成、摩擦轮已开启、三个发射电机在线、两摩擦轮绝对转速均不低于既有 `FRIC_SPEED_LIMIT=550`。N 右键/S 档有效自瞄自动开轮，但拨弹同时要求 `GetScCmdFire()`、有效视觉快照与鼠标左键按住；其余情况仍需 Fn 开轮。退出自瞄后恢复原 Fn 锁存，不把自动开轮写入手动开关。
- Fn 在初始化期间无效；C 档、遥控无效或云台状态失效后开轮状态清零，恢复后需先松开再重新按 Fn。
- 拨轮以 `(raw - 1024) / 660.0f` 归一化，`<= -0.95` 进入连发请求，`>= -0.90` 退出；这是对 −1 端点的容差及迟滞。
- 初始化要求 yaw、pitch 回中误差均小于 `0.03 rad`；3 秒超时表示失败，不能当成完成。工作中云台电机、板载陀螺仪/加速度计离线或反馈非有限时也禁止工作；失败后回 C 档可重试，失联恢复也会重新初始化。
- 云台状态完整发布，超过 `10 ms` 未更新时底盘与发射不使用旧状态。
- 未进入有效自瞄时：回正完成与跟随停止区共用 `VT13_CHASSIS_ALIGN_ANGLE_RAD=0.015 rad` 和 `VT13_CHASSIS_ALIGN_WZ_RAD_S=0.03 rad/s`，连续满足 `100 ms` 后恢复正常跟随。N 右键/S 档有效自瞄保留原固定回正完成条件 `0.03 rad / 0.05 rad/s` 持续 `100 ms`，完成后进入 BODY。角差按最短路径折返。
- VT13 退出小陀螺的回正阶段（`CHASSIS_SPIN_RETURN`）仍按 `CHASSIS_SPIN_RETURN_MAX_WZ=6.0 rad/s` 限制最终目标 `chassis.reference.wz`，限幅位于 PID 与角速度阻尼叠加之后。未进入有效自瞄时完成回正后，沿同一当前云台目标恢复正常跟随上限 `MAX_OUT_CHASSIS_FOLLOW_GIMBAL=15 rad/s`；N 右键/S 档有效自瞄按原固定方向回正后进入 BODY，角速度目标为 0。实际轮速估计 `P_wz` 仍受惯性和制动影响，目标限幅不保证瞬间减速。
- 仅未进入有效自瞄时回正，在角差小于 `CHASSIS_SPIN_RETURN_BRAKE_ANGLE=0.20 rad`（约11.5°）后，角速度阻尼由公共 `0.95` 随角差缩小平滑增至 `CHASSIS_SPIN_RETURN_NEAR_WZ_DAMPING=1.50`，提前增强制动；窗口外、正常 FOLLOW 及 N 右键/S 有效自瞄的固定回正均保持公共阻尼，最终速度上限仍为回正±6/FOLLOW±15。1.50是待实车验证的首轮对照值；改回0.95可关闭增强，窗口保持0.20。
- VT13 跟随/回正控制停止区仍为角差 <`0.015 rad`、实际角速度 <`0.03 rad/s` 时目标 `wz=0`。未进入有效自瞄时在此清跟随 PID 历史，回正转 FOLLOW 沿用控制器；N 右键/S 档有效自瞄保留原固定回正 PID 行为。yaw 编码器中值当前为用户现场值 `GIMBAL_DIRECT_YAW_MID=-0.540360451`，机械效果待实车核验。
- 各发送函数再次检查失能条件并清除残留输出。零速度参考下的 PID 制动力不等于失能；C 档/失联直接发送零输出。
- 保留原连发速度、堵转反转、PID 和自瞄控制器参数。本次没有新增热量门控，不能把已有热量参数表述为已生效保护。

## 代码接口与数据流

```text
VT03 UART → Vt13ReadInput → Vt13ReadControl
                             ├─ 云台：初始化 / 手动 / 自瞄
                             ├─ 底盘：跟随 / 底盘坐标 / 旋转 / 回正
                             └─ 发射：Fn/自动开轮 + 拨轮/左键连发 + 视觉与左键联合许可
视觉完整快照 → 云台实际自瞄状态与火控许可 → 底盘、发射
```

- `vt13_control.h`：`Vt13ControlInput`、`Vt13ReadControl()` 和纯状态机。映射函数不维护按键边沿，重复读取同一帧没有副作用。
- `move_x=normalized[3]`、`move_y=-normalized[2]`；`yaw_input=normalized[0]`、`pitch_input=normalized[1]`。2026-11-22 按用户反馈“前后左右对应原右左后前”交换控制层平移轴；接收层原始通道、已有左轴交换及云台增量控制符号保持，修正后方向待实车逐轴确认。
- `GimbalReadControlStatus()`：读取初始化、实际工作/自瞄状态、火控、世界 yaw、关节 yaw 和时间戳。由云台任务单写，其他任务只使用完整副本。
- `VisionReadControl()`：读取同一条已校验视觉命令与其接收时间，原协议线格式和 `mode=0/1/2` 含义保持。
- 未进入有效自瞄时的回正与正常跟随都使用本拍快照 `yaw_joint`；N 右键/S 档有效自瞄仍用 `wrap(return_heading-wrap(yaw_world-yaw_joint))` 作固定回正误差，随后进入 BODY。是否有效自瞄按同拍 `auto_active` 判断；回正期间目标得失会按当前实际状态选择路径。
